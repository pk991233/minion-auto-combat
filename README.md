# 小怪自動戰鬥 0.1.1

## 透過 Foundry 安裝

在 Foundry 啟動設定頁選擇「附加模組 → 安裝模組」，將下列網址貼入底部的 Manifest URL 欄位並按「安裝」。進入世界後，在「管理模組」啟用「小怪自動戰鬥」。

```text
https://github.com/pk991233/minion-auto-combat/releases/latest/download/module.json
```

也可[下載 v0.1.1 安裝 ZIP](https://github.com/pk991233/minion-auto-combat/releases/download/v0.1.1/minion-auto-combat-0.1.1.zip) 手動安裝。

GM 可以替個別 NPC Token 開啟「自動戰鬥」。輪到牠時，模組會選擇最近的玩家角色或友好單位、移動到射程內、執行指定攻擊，然後推進先攻。GM 可以在角色效果清單或 Token 設定中途停用效果。

## 安裝與第一次使用

1. 在 Foundry 的使用者資料夾建立 `Data/modules/minion-auto-combat/`，將本 ZIP 的內容直接解壓縮到其中。確認路徑是 `Data/modules/minion-auto-combat/module.json`。
2. 重新啟動 Foundry，進入 dnd5e 世界，在「遊戲設定 → 管理模組」啟用「小怪自動戰鬥」，儲存並重新載入。
3. GM 在地圖上以滑鼠右鍵點 NPC Token，按左側機器人圖示「小怪自動戰鬥設定」。在每一列選活動、填寫次數。點「新增攻擊」可接著排下一種。
4. 勾選「啟用此 Token 的自動戰鬥」並儲存。將 NPC 加入先攻，開始戰鬥或推進到牠的回合。Foundry 指派的主控 GM 需要在線、開著戰鬥場景，且遊戲已解除暫停。
5. 要停用時，在同一視窗取消勾選並儲存，也可以在角色卡停用或刪除帶有該 Token 名稱的「自動戰鬥」效果。共用角色卡的 Token 各自有開關和攻擊順序。

例如「啃咬一次、爪擊兩次」，第一列選「啃咬」並填 1，第二列選「爪擊」並填 2。三下各自擲命中，命中才擲該下的傷害。若目標在中途倒下，下一擊會重新選最近的有效目標。

## 0.1.1 的回合處理

遭遇可以綁定場景，也可以維持未連結。輪到小怪時，模組依參戰 Token 所屬的場景判斷，主控 GM 需檢視該場景。若在小怪回合開始後才開啟效果，尚未執行的回合會開始自動處理。
    
使用 Midi-QOL 的攻擊與傷害戲法時，模組把選定的目標交給 Midi-QOL，每下等待該活動結束後再執行下一下。命中、豁免、反應提示與實際扣血依 Midi-QOL 世界設定處理。聊天卡若等待 GM 或玩家回應，完成該步後才會推進。原生 dnd5e 活動仍使用本模組的「自動套用傷害」設定。

## 選擇攻擊

- 普通小怪預選第一個武器攻擊。模組可從名稱或系統識別碼辨識「多重攻擊」，並嘗試讀取描述裡明列的攻擊名稱與次數。可任選武器、含替換條件，或無法辨識的翻譯文字，請由 GM 選定一組合法的順序並儲存。
- 可選武器、帶攻擊活動的怪物特性，以及具有攻擊擲骰或單一屬性豁免傷害活動的戲法。範圍模板、有環位法術、反應與附贈動作均排除。一次選定一個目標。多射線需依角色資料設定次數。
- 使用 dnd5e 原生的活動消耗、攻擊骰、傷害骰和傷害套用。預設自動扣血，系統會處理傷害類型、抗性、免疫及暫時生命值。想由 GM 手動扣血，可以在「設定 → 模組設定 → 小怪自動戰鬥」關閉「自動套用傷害」。
- 附帶擒抱、推位、擊倒、可選擇的附加效果，與描述文字中的特殊戰術，交由 GM 裁定。

## 選敵、移動與狀態

| 情況 | 小怪的處理 |
| --- | --- |
| 選敵 | 從同場景找最近的友好 Token 或由玩家擁有且未設為敵對的角色。隱藏、死亡、已擊敗、生命值為 0 或有全掩護者略過。 |
| 移動 | 用步行速度靠近，在正常射程或觸及距離內停下。路線會檢查牆、閉門、Token 佔位及場景邊界。距離計入體型佔格與高度差。超過一回合步速時，下回合繼續。 |
| 遠程武器 | 優先靠近正常射程。如果用完步速後仍在長射程內，帶劣勢射擊。身旁 5 呎內有可威脅自己的對手，遠程攻擊也有劣勢。 |
| 自身束縛 | 步速為 0。仍能攻擊射程內的目標，攻擊帶劣勢。 |
| 自身伏地 | 以爬行接近，移動消耗加倍，攻擊帶劣勢。 |
| 目標伏地 | 相距 5 呎以內，攻擊有優勢。相距超過 5 呎，攻擊有劣勢。長觸及武器同樣看實際距離。 |
| 多種優劣勢 | 同時具有任何優勢與劣勢時，擲普通攻擊骰。另有處理目盲、中毒、麻痺、震懾等明確狀態。 |
| 遠得打不到、無目標、無法行動 | 略過無法執行的攻擊並推進到下一回合。 |
| 停用或中斷 | 效果已停用的 Token 完全由 GM 操作。連打中停用會停止後續步驟，已完成的移動或骰子保留。如果擲骰被其他流程取消或執行出錯，該回合交回 GM。 |

地面移動採有限範圍尋路。飛行、爬牆、困難地形、藉機攻擊及需要視覺特感判定的隱形規則由 GM 處理。自動回合開始後會留下執行紀錄，重新載入或退回相同輪次與角色時，GM 可以手動接手。若全場只剩自動小怪，完成一輪後會等 GM 推進。
